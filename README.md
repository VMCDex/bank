# Корпоративный сайт банка

Сайт банка с публичной частью и административной панелью для управления продуктами. Клиент смотрит кредиты, вклады и карты и оставляет заявку онлайн, сотрудник управляет каталогом и настройками.

Проект выполнен по учебному техническому заданию, максимально приближенному к требованиям финтех-сектора, во время производственной практики.

## Возможности

Публичная часть:

- главная страница, разделы «Частным лицам», «Бизнес», «О банке»;
- каталоги кредитов, вкладов и карт, детальная страница каждого продукта;
- форма онлайн-заявки с серверной валидацией (ФИО, телефон в российском формате, существующий продукт).

Административная панель:

- вход по логину и паролю;
- полноценный CRUD банковских продуктов;
- безопасная загрузка изображений (JPG, JPEG, PNG, WEBP, до 2 МБ);
- настройка email-адреса, на который уходят заявки.

Адаптивная вёрстка с общими компонентами (хедер, футер, слайдер, карточки).

## Стек

- PHP 8.2+, Laravel 12
- SQLite по умолчанию, MySQL поддерживается через `.env`
- Blade, HTML5, CSS3, JavaScript
- Vite, Tailwind CSS 4 (используются в стартовом шаблоне Laravel, для работы сайта сборка не нужна)

## Структура

```text
app/Http/Controllers/
  PageController.php        публичные страницы
  ProductController.php     каталог и CRUD в админке
  ApplicationController.php приём заявок
  AuthController.php        вход и выход
  Admin/SettingController.php настройки
app/Models/                 Product, Application, Setting, User
resources/views/            страницы, лейаут, админка
routes/web.php              маршруты
```

## Установка

Нужны PHP 8.2+, Composer и Node.js.

```bash
git clone https://github.com/VMCDex/bank.git
cd bank
composer install
cp .env.example .env
php artisan key:generate
```

По умолчанию проект использует SQLite, отдельный сервер базы данных не нужен. Создайте файл базы, примените миграции и заполните её тестовыми данными:

```bash
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Сайт откроется на http://127.0.0.1:8000.

Чтобы работать с MySQL, поменяйте `DB_CONNECTION` и параметры `DB_*` в `.env`.

## Доступ в админ-панель

Страница входа: http://127.0.0.1:8000/login

| Логин | Пароль |
| --- | --- |
| `admin` | `password` |

После входа открывается управление продуктами (`/admin/products`) и настройки (`/admin/settings`). Администратор создан сидером, для продакшена пароль нужно сменить.

## Заявки и email

Заявки из формы сохраняются в таблицу `applications` и отправляются на адрес из настроек админки. По умолчанию в `.env` стоит `MAIL_MAILER=log`, поэтому письма пишутся в `storage/logs/laravel.log`. Для реальной отправки укажите SMTP в `MAIL_*`.
